فرمت اندازهٔ تصویر نهایی است، مانند اندازهٔ موردنیاز فروشگاه برای iPhone یا Android. فرمت‌های لازم پروژه را فعال کنید.

طرح یک اندازهٔ پایه دارد. با انتخاب فرمت دیگر، طرح متناسب می‌شود. تنظیم اختصاصی یک فرمت می‌تواند فقط برای همان اندازه ذخیره شود.

پیش از خروجی همهٔ اندازه‌های فعال را در پیش‌نمایش ببینید؛ متن بلند و لبه‌های عکس در نسبت‌های مختلف متفاوت‌اند.
