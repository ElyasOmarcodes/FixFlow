## په کمپیوټر کې
- `Ctrl+Z`: وروستی بدلون بېرته ګرځوي.
- `Ctrl+Shift+Z`: بېرته ګرځول شوی بدلون بیا پلي کوي.
- `Ctrl+C`، `Ctrl+V`: ټاکلي پرتونه کاپي او نښلوي.
- `Ctrl+D`: ټاکلی پرت نقلوي.
- `Delete`: ټاکلی پرت ړنګوي.
- غشي پرت یو پیکسل خوځوي؛ له `Shift` سره لس پیکسله.
- `Ctrl+0`: ټول کینوس په کړکۍ کې برابروي.
- `Ctrl+1`: کینوس په اصلي زوم ښيي.
- `Ctrl+G`: ټاکلي پرتونه په ګروپ کې اچوي.
- `Escape`: پرانیستی ایډیټ یا پینل بندوي.

## په موبایل کې
د پرت د ټاکلو لپاره پرې یو ځل لمس وکړئ. متن په دوه ځله لمس یا د متن د بدلولو له تڼۍ ایډیټ کړئ. د کینوس د برابرولو تڼۍ هر وخت ټول ډیزاین بېرته ښکاره کوي. د بېرته او بیا تڼۍ د پاسنۍ کرښې په برخه کې دي. په Mac کې د Ctrl پر ځای Command کارېږي.
