AI دلته د ډیزاین د متنونو د ژباړې لپاره کارېږي. د API کیلي یوازې زیاتول په خپله عکس نه جوړوي او ټول اپ نه بدلوي.

## Gemini وصل کړئ
- تنظیمات پرانیزئ او د AI برخه وټاکئ.
- Google Gemini وټاکئ او خپله کیلي د API Key په خانه کې واچوئ.
- د تازه موډلونو تر راوتلو انتظار وکړئ. اپ لېست له Google څخه اخلي، د پاڼو ټولې پایلې راټولوي او د منځپانګې د تولید وړ موډلونه ښيي.
- د متن لپاره مناسب موډل وټاکئ او Test connection ووهئ. دا یوه کوچنۍ واقعي غوښتنه لېږي.
- د ژباړې برخه پرانیزئ، مطلوبې ژبې زیاتې کړئ او د AI ژباړه وکاروئ. پایله وګورئ او که اړتیا وي په لاس یې سمه کړئ.

## که کار نه کوي
د شبکې خطا د اتصال ستونزه ښيي؛ 401 یا 403 د کیلي/اجازې ستونزه کېدای شي؛ 429 د سهمیې یا غوښتنو د حد ستونزه ده. په لېست کې راتلل د وړیا یا نامحدود استعمال ضمانت نه دی. د تصویر، غږ یا نورو ځانګړو موډلونو نوم راتلل دا معنا نه لري چې د ژباړې له لارې ټولې ځانګړنې یې کارېږي.

کیلي په همدې وسیله ساتل کېږي او غوښتنه مستقیم خدمت‌ورکوونکي ته ځي. د ژباړې لپاره متن هغه خدمت ته لېږل کېږي؛ د هغه د API لګښتونه جلا دي. کیلي په سکرین‌شاټ یا عامه پروژه کې مه خپروئ.
