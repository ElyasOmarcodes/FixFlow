د پروژو له تڼۍ خپلې پروژې وګورئ، نوې پروژه جوړه کړئ یا پخوانۍ پرانیزئ. د نوم په وهلو یې نوم بدلولی شئ.

بدلونونه په همدې وسیله کې په اتومات ډول خوندي کېږي. دا د GitHub یا بلې وسیلې سره اتومات همغږي نه ده. د مهم کار د ساتلو لپاره د پروژې فایل هم اکسپورټ کړئ؛ بیا یې په بله وسیله واردولی شئ.

که په بل ټب کې همدا پروژه بدله شي، د ټکر خبرتیا راځي. د خپلو بدلونونو د ساتلو لپاره جلا کاپي خوندي کړئ. د اپ د معلوماتو له پاکولو مخکې بیک‌اپ واخلئ.
